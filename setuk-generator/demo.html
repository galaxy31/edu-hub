🎓 세특 생성기
구글 클래스룸 제출물 기반 · 세부능력 및 특기사항 초안 작성 도구

1. AI 설정

실제 앱에서는 여기에 본인 API 키를 한 번만 저장하면 됩니다(본인 계정에만 저장). 데모에서는 키가 필요 없습니다.

2. 수업 / 과제

먼저 수업을 선택하세요.
선택한 과제들의 제출물을 학생별로 통합 분석합니다.
세특 작성 지침(프롬프트) 보기
{학생이름}, {내용} 자리표시자는 자동으로 채워집니다.
💾 실제 앱에서 시트로 저장을 누르면 내 드라이브의 "세특 생성 결과" 스프레드시트에 선택한 수업 이름으로 시트가 만들어져 저장됩니다.

3. 스캔 → 생성 → 저장

왼쪽에서 수업 목록 불러오기 → 수업·과제를 선택한 뒤
① 제출물 스캔을 누르면 학생별 카드가 여기에 표시됩니다.
